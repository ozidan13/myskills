## ⚡ 1-Click Auto-Discovery Installer (`install.bat`)

`install.bat` is a **self-contained Windows `.bat` installer** that **automatically discovers all skill folders** inside this repository every time you run it — drop any new skill folder in the future and run `install.bat`, and it will appear automatically!

### Interactive Mode (Double-Click or Terminal)
Double-click **`install.bat`** in File Explorer, or run:
```bat
git clone https://github.com/ozidan13/myskills.git
cd myskills
.\install.bat
```

### Supported Targets in `install.bat`
1. **Antigravity Global** (`%USERPROFILE%\.gemini\config\skills`)
2. **OpenCode Global** (`%USERPROFILE%\.config\opencode\skills`)
3. **OpenCode Project Workspace** (`<project>\.opencode\skills`)
4. **Claude Code Global** (`%USERPROFILE%\.claude\skills`)
5. **Project Workspace** (`<project>\.agents\skills` — Cursor, Windsurf, Cline, Roo Code, Antigravity)
6. **ALL Global Apps at Once** (Antigravity + OpenCode + Claude Code simultaneously!)
7. **Custom Folder Path**

### Direct CLI Shortcuts (Non-Interactive)
```bat
:: Install all skills to Antigravity Global
.\install.bat Global

:: Install all skills to OpenCode Global (~/.config/opencode/skills)
.\install.bat OpenCode

:: Install all skills to OpenCode Project Workspace (.opencode/skills)
.\install.bat OpenCodeWorkspace "C:\path\to\your\project"

:: Install all skills to Antigravity + OpenCode + Claude Code globally at once
.\install.bat AllGlobal
```

### macOS / Linux (`install.sh`)
```bash
chmod +x install.sh
./install.sh
```
